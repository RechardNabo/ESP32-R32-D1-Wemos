What is ModBus TCP/IP?

ModBus TCP/IP is an industrial communication protocol used for transmitting information between electronic devices in industrial automation systems. It enables your irrigation system to communicate with programmable logic controllers (PLCs), SCADA systems, and other industrial equipment.

ModBus Register Map

The following registers are available for reading and writing values to control the irrigation system. Use these addresses in your ModBus client application.

Address Type Description Access Units
40001 Holding Register Temperature Read Only 0.1 °C
40002 Holding Register Humidity Read Only 0.1 %
40003 Holding Register Pressure Read Only 0.1 hPa
40004 Holding Register Soil Moisture Zone 1 Read Only 0.1 %
40005 Holding Register Soil Moisture Zone 2 Read Only 0.1 %
40006 Holding Register Soil Moisture Zone 3 Read Only 0.1 %
40101 Holding Register Zone 1 Valve Control Read/Write 0=Off, 1=On
40102 Holding Register Zone 2 Valve Control Read/Write 0=Off, 1=On
40103 Holding Register Zone 3 Valve Control Read/Write 0=Off, 1=On
40201 Holding Register System Mode Read/Write 0=Manual, 1=Auto
40202 Holding Register Alarm Status Read Only Bit Field

Example Code

Here's an example of how to read the temperature value from register 40001 using a Python ModBus client:

from pymodbus.client.sync import ModbusTcpClient # Connect to the ModBus server client = ModbusTcpClient('192.168.1.100', port=502) connection = client.connect() # Read the temperature from register 40001 # Note: Modbus addresses are 0-based, so register 40001 is at address 0 response = client.read_holding_registers(address=0, count=1, unit=1) if not response.isError(): # Convert the raw value to temperature (divide by 10 for 0.1°C precision) temperature = response.registers[0] / 10.0 print(f"Current temperature: {temperature}°C") else: print("Error reading temperature") # Close the connection client.close()
